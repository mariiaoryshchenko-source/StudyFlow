# StudyFlow

## Опис проєкту

StudyFlow — вебплатформа для планування навчання студентів.

Платформа допомагає студентам організовувати навчальні завдання, встановлювати дедлайни, переглядати календар та отримувати нагадування.

## Основні функції

- створення навчальних завдань;
- встановлення дедлайнів;
- перегляд завдань у календарі;
- нагадування про наближення дедлайнів;
- редагування та видалення завдань.

## Мета проєкту

Створити зручний вебінструмент, який допоможе студентам організувати навчальний процес та контролювати виконання завдань.
