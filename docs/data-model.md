# StudyFlow — Data Model

## Сущність Task

Основна сутність системи для зберігання навчальних завдань.

### Поля

- id — унікальний ідентифікатор завдання;
- title — назва завдання;
- description — опис завдання;
- deadline — кінцевий термін виконання;
- status — поточний статус завдання;
- created_at — дата створення;
- user_id — ідентифікатор користувача.

## Статуси завдання

- To Do — завдання створене;
- In Progress — завдання виконується;
- Done — завдання виконане.

## Основний зв'язок

Один користувач може мати багато навчальних завдань.

User → Tasks
