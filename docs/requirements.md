# StudyFlow — Requirements

## Функціональні вимоги

1. Користувач може створювати навчальні завдання.
2. Користувач може встановлювати дедлайн для завдання.
3. Користувач може переглядати завдання у календарі.
4. Система може надсилати нагадування про наближення дедлайнів.
5. Користувач може редагувати та видаляти завдання.

## Основні сценарії

### Створення завдання

Користувач вводить назву завдання, опис та дедлайн. Після збереження завдання відображається у списку та календарі.

### Контроль дедлайнів

Система відображає наближення дедлайнів та надсилає користувачу нагадування.

## Мета MVP

Реалізувати базову версію StudyFlow для створення навчальних завдань, встановлення дедлайнів та перегляду навчального календаря.
